# Changelog

## 0.1.0 - 2026-11-20

Initial release.

### Added

- Responsive documentation layout with a Fluent UI header and sidebar navigation.
- English and Simplified Chinese interface translations, localized routes, and a light/dark toggle using Fluent's web light and dark themes.
- Locale-aware fuzzy search with a dialog and the `Ctrl+K` / `⌘K` shortcut.
- Optional GitHub and Donate links from project metadata.
- Markdown and MDX code blocks highlighted with Shiki, including copy controls.
- Page outline in a table of contents that stays in view on wide screens and opens from a floating button on small screens.
